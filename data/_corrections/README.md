# Bundled corrections

Decisions about imported data — a type set, a subtype chosen, a duplicate
removed, an item moved to the list it belongs in, a description repaired. They
are applied as the last phase of an import.

**A correction can never create an item.** It names an item and states what
should change about it. If your library has no such item — because you do not
own that book — the correction is skipped and counted, never applied. Nothing
here can add an item you did not import yourself from a book you own.
