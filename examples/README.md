# Examples

**Nothing in this directory is copyrighted game content.**

Every item here is invented — an "Example Autopistol" with numbers chosen to
show the shape of a record, not to reproduce one. They exist so a contributor
can see what the extractor emits and what the schemas expect without owning a
single book.

Real extracted data lives in `data/`, which is gitignored and has never been
committed. See the repository README under *What this does not contain*.
